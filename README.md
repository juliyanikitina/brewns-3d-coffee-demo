# BREWNS — 3D Coffee Experience

Демонстрационный одностраничный сайт для портфолио веб-разработки.

## Возможности

- интерактивная 3D-сцена на Three.js;
- плавная прокрутка Lenis;
- адаптивная вёрстка для компьютеров, планшетов и телефонов;
- анимации появления и реакции на указатель;
- интерактивные карточки меню;
- анимированный чек заказа;
- экран загрузки;
- поддержка `prefers-reduced-motion`;
- семантическая HTML-разметка.

## Запуск

Проект состоит из одного файла `index.html`. Для полноценной загрузки ES-модулей откройте его через локальный HTTP-сервер, например:

```bash
python -m http.server 4173
```

Затем перейдите по адресу `http://127.0.0.1:4173/`.

## Технологии

HTML, CSS, JavaScript, Three.js, WebGL, Lenis, GLB/Draco.
